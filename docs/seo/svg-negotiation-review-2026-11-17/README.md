## Standalone origin and local verification

`tools/svg-negotiation-payload.py` is an offline compiler. It has no FTPS, Cloudflare, publication or purge capability. Exact golden source hashes, bounded explicit epochs, fixed modes and a single uncompiled template boundary bind ten declared files. The origin PHP contains an embedded manifest, two aliases and six fixed representations. It reads the selected body once, verifies its size/hash and emits those same bytes; unknown paths, aliases, changed files and invalid manifests cannot choose arbitrary files or fall back to unchecked content. WordPress, database, session, email, forms and consent APIs are absent.

The one-hour compiled expiry is checked before selection and after reading. HTTP queries cannot rearm it. Unknown/direct/array/path-escape aliases return 404; other methods return 405. Malformed, conflicting or oversized encoding fields return 400, and no acceptable representation returns 406. Among acceptable Brotli/gzip representations, the highest quality wins, with Brotli first on a tie. An explicit identity weight participates; otherwise identity is the permitted uncompressed fallback unless excluded. Absent and empty fields are distinct. This policy follows the content-coding preference/fallback distinction in [RFC 9110 section 12.5.3](https://www.rfc-editor.org/rfc/rfc9110.html#section-12.5.3); it is not a whole-HTTP conformance certificate.

The response binds the origin-observed field using a presence flag and SHA256 after removing only field-edge optional whitespace. Token order, internal whitespace and all quality values remain in that digest. The local router's two negative controls deliberately replace the incoming field; the visitor expectation rejects both the wrong status and changed digest. This proves that the verifier detects that modeled mechanism. It does not prove the cause of historical Cloudflare behavior.

No-store and public modes use distinct compiled namespaces. Both use SVG MIME, correct coding/length, noindex/nofollow, `no-transform`, `Vary: Accept-Encoding` and a strong validator derived from the selected wire bytes. Public mode has a bounded 60-second TTL. Same-representation GET/HEAD validators return bodyless 304; different representations retain distinct strong validators. Weak If-None-Match, lists, wildcard, conditional precedence, both obsolete HTTP-date formats, invalid dates, strong If-Match and failed preconditions are exercised. Range is deliberately ignored as a complete 200 response with `Accept-Ranges: none`; partial delivery is not claimed. Errors are no-store.

The 233 actual local requests cover these cases for both originals, including expiry/future-manifest and late changed-file refusals. Adversarial compiler cases reject namespace injection, ambiguous epochs/modes, partial/duplicate template boundaries and a late changed original without a complete payload. All forty known fixture files are exactly retained/restored after the run. The owned PHP process closes; source hashes remain exact. The local router substitutes only for the known probe aliases and direct-path negative tests. It does not establish LiteSpeed rewriting, Cloudflare header preservation, edge cache/HIT/conditional behavior or production acceptance.

The first public-response inspection stops on an unsupported harness assumption that ETag must be present; its eight real responses remain retained. The corrected complete baseline uses the actual Last-Modified field. Initial local runs each retain 19/20 checks: PHP removes leading header whitespace but can retain trailing whitespace. The diagnostic and verifier now canonicalize only field-edge whitespace; explicit internal-whitespace/quality cases pass.
